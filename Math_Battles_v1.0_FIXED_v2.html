Setup checklist for the ranked server
  1. In Supabase Auth settings, enable Anonymous Sign-Ins.
  2. Run the SQL migration from math_boss_ranked_backend/supabase/migrations/.
  3. Deploy the ranked-match Edge Function from the included backend bundle.
  4. In the existing “Connect a shared online leaderboard” settings below, enter your project URL and public publishable/anon key, then connect here.
  5. Publish this HTML on an HTTPS website and test with two different browser profiles/devices.

Never put a Supabase service-role/secret key in this page. It belongs only in server-side function secrets. Anonymous guest identity is stored by the browser; clearing browser data can lose the guest identity. The online server isn't deployed automatically by this HTML file.

Protection boundary: the server controls prompts, answer keys, timers, scoring and match results. It makes direct browser score edits ineffective. It cannot prevent screenshots, players sharing answers, outside calculators, multiple accounts, or every form of network abuse.
